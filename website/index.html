Python est inclus dans ces applications. FFmpeg et ffprobe sont encore à installer séparément pour l’import, l’aperçu et l’export.

Installer FFmpeg sur macOS

Avec Homebrew installé, ouvrez le Terminal :

brew install ffmpeg
Installer FFmpeg sur Windows

Dans l’Invite de commandes, puis redémarrez Kut-Studio après l’installation :

winget install Gyan.FFmpeg
Préparer Linux (Debian / Ubuntu)
sudo apt install ffmpeg libegl1

LA SUITE DE KUT-STUDIO

Les prochaines
évolutions.

Des améliorations pour installer plus facilement, monter plus confortablement et aller plus loin dans la création.

  1. 01
    Améliorations prévues

    Une installation encore plus simple

    Poursuivre la signature des applications Windows et l’installation automatique fiable. Le téléchargement vérifié et l’installation assistée sont désormais intégrés au code ; la signature et la notarisation macOS dépendent de la configuration des publications.

  2. 02
    Améliorations prévues

    Un montage plus fluide

    Améliorer les performances de l’aperçu et de la timeline sur les gros projets, tout en poursuivant la stabilisation du logiciel.

  3. 03
    Améliorations prévues

    Davantage d’effets sur GPU

    Étendre l’aperçu GPU aux LUTs, à l’étalonnage couleur et aux scopes pour enrichir le travail de l’image.

  4. 04
    Améliorations prévues

    Des animations plus riches

    Animer les textes caractère par caractère, les couleurs et les sommets des masques, et appliquer des effets à l’intérieur des groupes.

  5. 05
    Pistes à plus long terme

    Des ralentis plus avancés

    Explorer l’accélération du flux optique sur GPU, l’interpolation neuronale et le traitement en temps réel. Ces extensions ne sont pas encore commencées.

  6. 06
    Pistes à plus long terme

    Un multicam plus ambitieux

    Explorer les proxies multicam automatiques, les configurations de 16 angles ou plus, la capture en direct et des outils de synchronisation plus avancés. Ces extensions ne sont pas encore commencées.

Ces objectifs sont issus de la feuille de route du projet. Aucune date de sortie n’est annoncée ; les priorités et le contenu peuvent évoluer.

Comment fonctionnent les mises à jour ?

La nouvelle recherche de mises à jour consulte uniquement les releases numérotées de GitHub, puis vérifie le paquet téléchargé. L’installation reste assistée et attend la fermeture normale de l’application. Les paquets numérotés sont sur les releases GitHub. La version du projet est 0.6.1 ; les fichiers proposés ici suivent la dernière release publiée.

Kut-Studio est-il gratuit ?

Le code source est disponible sous licence MIT. Vous pouvez l’utiliser, l’étudier et contribuer au projet.

Sur quels systèmes fonctionne-t-il ?

Les applications téléchargeables sont compilées pour macOS Apple Silicon, Windows x64 et Linux x86_64. Python est inclus. FFmpeg et ffprobe restent nécessaires pour travailler avec vos médias.

Est-ce un logiciel en ligne ?

Kut-Studio est une application de bureau. Vos fichiers sont traités localement sur votre ordinateur ; ce site présente le logiciel et vous guide vers son installation.

Comment contribuer ou signaler un problème ?

Consultez le dépôt GitHub pour explorer le code. Pour un problème, ouvrez un signalement en décrivant votre système et les étapes pour le reproduire.
