Aplicación lista para abrir. FFmpeg por añadir.

Python está incluido en estas aplicaciones. FFmpeg y ffprobe aún deben instalarse por separado para la importación, la vista previa y la exportación.

Instalar FFmpeg en macOS

Con Homebrew instalado, abre Terminal:

brew install ffmpeg
Instalar FFmpeg en Windows

En el Símbolo del sistema, y reinicia Kut-Studio después de la instalación:

winget install Gyan.FFmpeg
Preparar Linux (Debian / Ubuntu)
sudo apt install ffmpeg libegl1

LA CONTINUACIÓN DE KUT-STUDIO

Las próximas
evoluciones.

Mejoras para instalar con más facilidad, montar con más comodidad e ir más lejos en la creación.

  1. 01
    Mejoras previstas

    Una instalación aún más simple

    Seguir con la firma de las aplicaciones Windows y una instalación automática fiable. La descarga verificada y la instalación asistida ya están en el código; la firma y la notarización de macOS dependen de la configuración de las publicaciones.

  2. 02
    Mejoras previstas

    Un montaje más fluido

    Mejorar el rendimiento de la vista previa y de la línea de tiempo en los proyectos grandes, y seguir estabilizando el programa.

  3. 03
    Mejoras previstas

    Más efectos en la GPU

    Extender la vista previa GPU a las LUT, al etalonaje y a los scopes para enriquecer el trabajo de la imagen.

  4. 04
    Mejoras previstas

    Animaciones más ricas

    Animar los textos carácter a carácter, los colores y los vértices de las máscaras, y aplicar efectos dentro de los grupos.

  5. 05
    Pistas a más largo plazo

    Ralentíes más avanzados

    Explorar la aceleración del flujo óptico en GPU, la interpolación neuronal y el tratamiento en tiempo real. Estas extensiones aún no están empezadas.

  6. 06
    Pistas a más largo plazo

    Un multicam más ambicioso

    Explorar los proxies multicam automáticos, las configuraciones de 16 ángulos o más, la captura en directo y herramientas de sincronización más avanzadas. Estas extensiones aún no están empezadas.

Estos objetivos salen de la hoja de ruta del proyecto. No se anuncia ninguna fecha; las prioridades y el contenido pueden cambiar.

¿Cómo funcionan las actualizaciones?

La nueva búsqueda de actualizaciones consulta solo las releases numeradas de GitHub y luego verifica el paquete descargado. La instalación sigue asistida y espera el cierre normal de la aplicación. Los paquetes numerados están en las releases de GitHub. La versión del proyecto es 0.6.3; los archivos propuestos aquí siguen la última release publicada.

¿Kut-Studio es gratuito?

El código fuente está disponible bajo licencia MIT. Puedes usarlo, estudiarlo y contribuir al proyecto.

¿En qué sistemas funciona?

Las aplicaciones descargables están compiladas para macOS Apple Silicon, Windows x64 y Linux x86_64. Python está incluido. FFmpeg y ffprobe siguen siendo necesarios para trabajar con tus medios.

¿Es un programa en línea?

Kut-Studio es una aplicación de escritorio. Tus archivos se procesan localmente en tu ordenador; este sitio presenta el programa y te guía para instalarlo.

¿Cómo contribuir o señalar un problema?

Consulta el repositorio de GitHub para explorar el código. Para un problema, abre un informe describiendo tu sistema y los pasos para reproducirlo.
