A FEW LANDMARKS

Before you
begin.

How do updates work?

The new update check only looks at numbered GitHub releases, then verifies the downloaded package. Installation stays assisted when updating from 0.9.0 to 0.9.1 and on Windows and Linux. Starting with 0.9.1 on macOS, when the release signature is verified and the app sits in a writable folder (for example Applications), “Install and restart” updates it on its own and goes back to the previous version if the new one does not start. Numbered packages live on GitHub releases. The project version is 0.9.1; the files offered here follow the latest published release.

Is Kut-Studio free?

The source code is available under the MIT license. You can use it, study it and contribute to the project.

Which systems does it run on?

The downloadable apps are built for macOS Apple Silicon, Windows x64 and Linux x86_64. Python is included. FFmpeg and ffprobe are still required to work with your media.

Is it an online app?

Kut-Studio is a desktop application. Your files are processed locally on your computer; this site presents the software and guides you to install it.

How do I contribute or report a problem?

See the GitHub repository to explore the code. For a problem, open an issue describing your system and the steps to reproduce it.
